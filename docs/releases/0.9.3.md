# Pinyon Shift 0.9.3

A fix for Android games that closed at launch.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.9.3**; the game is built again after the update, and saves,
settings and DLC stay where they are. On Android the fix comes with the APK
built from this version.

## Fixed

- **The Android game closed about a second after Play** on 0.9.0 to 0.9.2,
  before the title screen, on devices that use the system's own Adreno or
  Mali Vulkan driver, such as the AYN Odin 2 and the Anbernic RG557 (#1101,
  #1107). The window's drawing pass started without the colour it clears
  to, and those drivers read the missing colour as a null pointer. Devices
  where the app loads the Mesa Turnip driver, and desktop GPUs, were not
  affected. Players who added `present_render_pass_clear = false` to get
  past it can remove the line
  ([troubleshooting](https://arcanite24.github.io/pinyon-shift/troubleshooting/)).
- **Windows setup stopped with exit code 87** while updating an existing
  Visual Studio whose installer is version 4.12 (Visual Studio 18): setup
  passed an option that installer no longer accepts (likely #549). Setup
  now leaves it out.

## Known limitations

The limitations listed for [0.8.0](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.8.0.md#known-limitations) still apply.
