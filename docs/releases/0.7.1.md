# Pinyon Shift 0.7.1

Setup on Windows failed for players whose user folder has an accented or
other non-ASCII name. This release fixes that and changes nothing else.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. 0.6.x and 0.7.0 launchers offer this
update from **Update to 0.7.1**; the game is built again after the update,
and saves, settings and DLC stay where they are.

## Fixed

- **"Downloading ShiftGlue failed" with `schannel: failed to open CA
  file`**: under a user folder such as `C:\Users\Théo`, every attempt to
  download ShiftGlue failed. Setup pointed its own Git at a certificate
  file that Windows could not open from that path. Git now checks
  certificates against Windows' certificate store, which also still
  ignores a broken certificate setting left by an old Git install (#604).
  PCs with Git for Windows installed were not affected.

## Known limitations

The limitations listed for [0.7.0](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.7.0.md#known-limitations) still apply.
