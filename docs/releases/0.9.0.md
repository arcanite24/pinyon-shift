# Pinyon Shift 0.9.0

Frame generation, ambient occlusion, save sync and much shorter loading
screens, plus setup fixes for Android, macOS and the v4 title update.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.9.0**; the game is built again after the update, and saves,
settings and DLC stay where they are.

## New

- **Frame generation** under F6 > DISPLAY > FRAME GENERATION: a generated
  frame between each two real ones, from the game's depth and camera
  motion. **FSR 3** runs on any GPU; **DLSS** is listed on NVIDIA RTX 40 and
  newer. The game then renders at no more than half your display's refresh
  rate, so it works best at 100 Hz or more. The HUD and the F3 panel are
  drawn on every frame, not generated, and it works with HDR. Offered on
  Windows, Linux and the Steam Deck. Fast-moving cars can still show
  ghosting and it adds input lag (#1094). See
  [Frame generation](https://arcanite24.github.io/pinyon-shift/playing/#frame-generation).
- **Ambient occlusion** under GRAPHICS > AMBIENT OCCLUSION: contact shade
  under cars, along kerbs and in cockpits, which FH1 never had. Off by
  default.
- **FRAME RATE** is now one setting: DISPLAY, 30, 40, 60, 120, 144 or 240.
  The separate presentation limit, which dropped frames the game had
  already rendered when set below the game's rate, is gone; VSYNC alone
  decides whether frames wait for the display.
- **Save sync** through a folder-sync app (Syncthing, Dropbox, OneDrive and
  the like): each device publishes its save to a folder you choose in the
  launcher, and at start the game loads a save that continued from its own
  and merges achievements. When both devices played, SETTINGS > PROFILE >
  SAVE SYNC lets you choose; every import is backed up first.
- **SCENE RESOLUTION 540P** under GRAPHICS for weaker GPUs: the 3D scene at
  960x540, keeping the full static world (#1070). It saved 15.6 % of the
  frame on an Intel UHD 620.
- **Resolution scale, MSAA and texture size apply at once**, without a
  restart.
- **Shorter loading screens**: the game waited for a minimum time on each
  tip screen however early loading finished. Title to free roam went from
  1.5 to 0.5 s and car select to race from 4.7 to 1.7 s on an SSD.
- **The mouse pointer hides** after a few seconds without mouse movement
  (#1076).
- **The console keyboard accepts typing** from a physical keyboard.
- **Linux on ARM64 (experimental, from source only)**: builds for ARM
  Linux handhelds such as the AYN Odin 2 Portal under Armada OS, against
  the Steam Runtime 4 arm64 SDK, now built and tested on every change in
  CI. There is no launcher for it yet; see
  [Platforms](https://arcanite24.github.io/pinyon-shift/platforms/).

## Faster

- **Steam Deck and Linux**: the scene's tiles are drawn in one pass (2.5 to
  3 ms less CPU a frame in a Deck race), the render thread's scene culling
  runs as native code, game code sits in 2 MiB pages, and LOW-SPEC 60,
  BALANCED 40 and ULTRA LOW 30 switch to simpler models sooner.
- **Audio** updates run at the console's 30 Hz rate instead of every
  rendered frame.
- **Loading** answers the game's file lookups from a folder listing instead
  of asking the disk each time.

## Fixed

- **Android: the build stopped with an AttributeError** once it had
  downloaded host objects, in every 0.8.x release (#1041, #1042, #1045),
  and unpacking the NDK into a long install folder failed (#1072).
- **v4 title update: setup refused a warning from 0.7.1** on Linux and macOS
  installs upgraded from that release (#1046, #1079), and a build folder
  could keep an old code generator after an update (#1081).
- **macOS: every launcher command stopped with ModuleNotFoundError** on the
  system Python 3.9 before setup could install its own (#1051).
- **macOS on exFAT drives**: tools landed one folder too deep (#1052); setup
  now stops on an exFAT or FAT drive and says how to install on an APFS
  disk image instead, since CMake cannot run there (#1053).
- **Setup refused an interrupted ShiftGlue download** as local changes; it
  now replaces it.
- **Windows: started from a PowerShell 7 prompt, setup failed** with
  "Get-FileHash is not recognized".
- **A settings file that cannot be read** used to be skipped silently, so
  the game started on its defaults; the log now names the file and the
  line.

## Known limitations

The limitations listed for [0.8.0](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.8.0.md#known-limitations) still apply.
