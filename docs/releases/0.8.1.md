# Pinyon Shift 0.8.1

0.8.0 setup on Windows stopped before building the game. This release
fixes that and adds an experimental launcher for Intel Macs.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.8.1**; the game is built again after the update, and saves,
settings and DLC stay where they are.

## Fixed

- **"Cannot bind argument to parameter 'BuildDirectory' because it is an
  empty string"**: with the prebuilt ShiftGlue kit, which 0.8.0 uses by
  default, Windows setup passed an empty folder to the step that notices a
  moved build folder, and stopped there (#1000). Setup now leaves out the
  ShiftGlue build folder that a kit build does not have. Linux, macOS and
  Android setup were not affected.

## Intel Macs (experimental)

`PinyonShift-Launcher-macos-x86_64.zip` is a launcher for Intel Macs on
macOS 13.3 or newer. Install and play it the same way as the Apple silicon
launcher; it downloads a ShiftGlue kit built for Intel. It has only run under
Rosetta on an Apple silicon Mac, where it reached free roam and drew it
correctly. It has not run on an Intel or AMD Mac GPU yet, so expect rendering
bugs and low frame rates on integrated graphics, and please report what you
see. Details in [macOS](https://github.com/arcanite24/pinyon-shift/blob/main/docs/MACOS.md#intel-macs-experimental).

## Known limitations

The limitations listed for [0.8.0](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.8.0.md#known-limitations) still apply.
