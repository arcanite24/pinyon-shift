# Pinyon Shift 0.6.1

Fixes for setups that 0.6.0 could not build (Linux and Steam Deck folders
with spaces, Android APKs), FSR 2, FSR 3 and DLSS on Windows without
files to add by hand, force feedback for racing wheels, fuller telemetry,
and Windows HDR switched on by the game.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. 0.6.0 launchers offer this update from
**Update to 0.6.1**; the game is built again after the update, and saves,
settings and DLC stay where they are.

## Fixed builds

- **Linux and Steam Deck**: setup stopped with `C compiler ABI info -
  failed` when the install folder had a space in its name, such as
  `Non-Steam Games` on an SD card; the toolchain now quotes its paths
  (#727). The FidelityFX build on SteamOS (`crtbeginS.o` or `-lgcc` not
  found) builds again (#681).
- **Android APK**: the source package now carries
  `config/performance/symbol-order-base.txt` and the other files the
  Android build reads (#716), and a build stopped part way no longer fails
  every later build with `build.ninja` missing (#763).

## New

- **Upscalers on Windows without extra files**: setup downloads AMD's signed
  FidelityFX runtime and NVIDIA's DLSS runtime and places them beside the
  game, so **F6 > DISPLAY > OUTPUT SCALING** offers FSR 2, FSR 3 and, on
  RTX cards, DLSS. When one can't run, the setting now says FSR 1 is used
  instead of naming the one you picked (#762, #670).
- **Racing wheel force feedback** (#337): the game drives a force-feedback
  wheel the way it drove the Xbox 360 wheel. The launcher's wheel screen
  binds steering, pedals, buttons and an H-shifter, tunes force feedback
  and rumble, and sets up telemetry; wheels made of separate USB devices
  bind through **F6 > CONTROLS > RACING WHEEL > SEPARATE DEVICES**.
- **Telemetry out** also sends the car's controls, idle RPM, each wheel's
  speed, slip angle and suspension travel, and road rumble. Pause screens
  send race off. `telemetry_udp_format = "horizon"` sends the Forza
  Horizon 4/5 layout; the default stays Forza Motorsport 7 on port 5300.
- **WINDOWS HDR** in **F6 > DISPLAY** turns Windows HDR on while the game
  runs and back off when it closes, even after a crash.
- **Camera**: chase height, distance, field of view and stiffness change
  live (#487), and the immersive camera works on the v4 build.
- **Trainer**: travel by road and set GPS destinations from the map (#485);
  FAST TRAVEL ANYWHERE keeps the title's own placement for markers it
  already allows.
- **Mods**: shader replacement mods load in mod order (#522), and a frame
  inspector shows surfaces, resolves and texture hashes (#529).
- **Android**: an Experimental setup option, **Allow GPUs without vertex
  shader stores**, lets Mali GPUs (Google Tensor, Exynos, Dimensity) start
  the game. It is off by default.

## Fixed

- **Shadows off**: car photos in the garage no longer come out with cyan or
  pink panels (#700), and the option reads **OFF BY DAY** (#733).
- **Wrong textures after editing a livery** (#628).
- **Hidden cars for sale** no longer include traffic-only models, and a
  save stuck on a blocked car loads with a fallback car (#669).
- A mod builder that wrote the settings file first no longer leaves the game
  without its default settings; cleared trainer settings stay cleared.
- The wheel and replay cameras the game uses in its own sequences are left
  alone when **DRIVING VIEW** is set.
- macOS builds with older Apple clang (#775).

## Faster

- With an overlay or <kbd>F3</kbd> open, frames are no longer presented
  twice, and the exposure readback no longer waits for the GPU every frame
  (1.5 to 1.8 ms less fence waiting a frame on an RTX 4080).
- Windows v4 builds use the same CPU baseline as base builds (#744).

## Known limitations

- Force feedback has not been tried on a physical wheel by the maintainer
  yet; it comes from the contributors who built it. Report wheels that
  misbehave on #337.
- The v4 build on Linux and macOS is tested in scripted routes only, and an
  Android build from those launchers is untested.
- DualSense over Bluetooth or off Windows is untested.
- AMD and Intel GPUs on PCs are not qualified yet; the Steam Deck is.
- DLSS is Windows only.
