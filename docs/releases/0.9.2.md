# Pinyon Shift 0.9.2

Faster low presets on Windows.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.9.2**; the game is built again after the update, and saves,
settings and DLC stay where they are.

## Faster

- **ULTRA LOW 30, LOW-SPEC 60 and BALANCED 40 translate shaders more
  cheaply on Windows.** They now specialize texture signs, use faster pixel
  math and let 2D texture fetches pick their own detail level
  (`spirv_specialize_texture_signs`, `spirv_fast_pixel_math`,
  `spirv_implicit_lod_2d`). On an Intel UHD 620 laptop the GPU frame took
  26-32 % less on the same race start, with no visible change in captures.
  The other presets keep them off, since an RTX 4080 measured no gain.
  A new Windows install starts with them on and a capable machine's first
  run turns them off with PERFORMANCE 120. Existing settings are not
  changed: choose one of those three presets again in the graphics settings to
  turn them on
  ([GPU optimizations](https://arcanite24.github.io/pinyon-shift/gpu-optimizations/)).
