# Pinyon Shift 0.3.1

These notes describe this historical release. Current builds support Vulkan
only; Direct3D 12 is legacy and unsupported. See [Building](../BUILDING.md).

A fix for first-time setup with Direct3D 12. Everything else is as in
[0.3.0](0.3.0.md).

## Fixed

- Setup with Direct3D 12 as the graphics API, which the 0.3.0 notes recommend
  for 3x and 4x, no longer stops while preparing graphics with "Cannot find
  path ...\pipeline\shader because it does not exist". Launching the game
  with Direct3D 12 after a Vulkan setup failed the same way (#322, #323).

If setup stopped with that error, run setup again with the 0.3.1 launcher.
Direct3D 12 is the graphics API to choose for 3x and 4x.

## Updating

Download **PinyonShift-Launcher.zip**, keep the two files together, and use the
ISO you dumped from your own disc. Your saves and settings stay where they are.
