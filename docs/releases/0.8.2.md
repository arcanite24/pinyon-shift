# Pinyon Shift 0.8.2

0.8.0 and 0.8.1 broke setup in three places: Windows setup from a disc image,
every Linux build, and the Android build on PCs without Git. This release
fixes them, fixes a Rally crash with database mods, and adds a mod manager to
the launcher.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.8.2**; the game is built again after the update, and saves,
settings and DLC stay where they are.

## Fixed

- **"can't open file ... tools\copy-disc-executables.py: No such file or
  directory"**: Windows setup from a disc image stopped while copying the
  game files, because the launcher download left that script out (#1014,
  #1016, #1018, #1020). It is shipped again. The extract-xiso workaround is
  no longer needed.
- **Linux: "relocation R_X86_64_64 cannot be used against local symbol;
  recompile with -fPIC"**: every Linux and Steam Deck build from the prebuilt
  ShiftGlue kit failed to link, because the build picked up the toolchain's
  own SDL3 library instead of the kit's (#1001, #1005, #1009, #1017). It now
  uses the kit's libraries.
- **Android: "The Android build stopped. Git is not available."**: since
  0.8.0 the PC build no longer installs Git, which the Android build still
  needed. The Android build now installs the pinned Git itself.
- **Crash when starting a Rally championship with mods**: on the base game,
  any enabled mod that changes the game database (Hidden cars, for example)
  hid the Rally database, and choosing a championship from F6 > HORIZON
  RALLY ran the game out of memory (#1024). Database mods now build on the
  Rally database when Rally is installed.
- **macOS: "No Vulkan GPU found" in Settings after a finished build**: the
  launcher's hardware check didn't find MoltenVK in a build made from the
  prebuilt kit, so it couldn't name the GPU or recommend a preset for it.
- **macOS: building from source with Xcode 16 on Apple silicon** failed with
  "'to_chars' is unavailable"; Apple silicon builds now target macOS 13.3, as
  Intel builds already did (#918).

## New

- **Mods panel in the launcher**: install mods from a ZIP or a folder, switch
  them on, change their order, remove them, and set the options a mod offers
  (#878). The same is available as `pinyon.py mods`. See
  [Modding](https://github.com/arcanite24/pinyon-shift/blob/main/docs/MODDING.md).
- **Festival pacing mod** (built in, off by default, base game only): scales
  what cars, upgrades and rims cost (0.25x to 3x) and the credits, wristband
  points and XP you earn (0.5x to 5x) (#879).
- **Head tracking** with opentrack turns the driver and hood cameras of the
  immersive camera mod; off by default (#817).
- **Field of view** goes up to 200 % (was 130 %) under Display > FIELD OF VIEW
  (#927).
- **For mod makers**: `pinyon.py import-mod` turns a folder or archive of
  changed game files into a mod that keeps only the files that differ from
  your own game (#917), and archives a mod adds are now listed in
  `zipmanifest.xml`, so the game opens them.

## Known limitations

The limitations listed for [0.8.0](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.8.0.md#known-limitations) still apply.
The Intel Mac launcher remains experimental.
