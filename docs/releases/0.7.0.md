# Pinyon Shift 0.7.0

This release installs the community UDLC pack from the launcher and imports
DLC from nested or split downloads. Database mods now work on the v4 build,
and the settings menu gets **QUIT GAME**. It also fixes builds on Android,
Steam Deck SD cards and macOS, and an update that kept running the old game.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. 0.6.x launchers offer this update from
**Update to 0.7.0**; the game is built again after the update, and saves,
settings and DLC stay where they are.

## New

- **UDLC pack** (#595): the launcher's **DLC** panel installs
  [UDLC v1.2](https://www.moddb.com/mods/forza-horizon-udlc-pack/downloads/udlcv12)
  and its optional Traffic Car Unlocker, community packages by Warshack4874
  that add cars from the Xbox 360 *Forza Horizon 2*. **Download from ModDB**
  opens the page in your browser and picks up the finished ZIPs; **Install
  UDLC** takes ZIPs you already have. Pinyon Shift checks them against
  pinned hashes and never downloads them itself. Turning UDLC off asks
  first, also turns the unlocker off, and hides owned UDLC cars until it
  is on again; the save file is not changed. See [DLC](https://arcanite24.github.io/pinyon-shift/dlc/#community-udlc).
- **DLC import from several sources** (#857): import accepts any number of
  files and folders at once, and looks inside ZIPs nested up to three
  levels, so a set shared as per-package ZIPs inside one ZIP, or split over
  several downloads, imports in one step. Packages it skips are named from
  their header with the reason.
- **Database mods on v4**: `db/*.sql` mods, the built-in hidden cars among
  them, did nothing on the v4 build, which reads its own database from the
  update. They now apply to that database as well; the installed update
  stays untouched.
- **QUIT GAME** is the last row of the **F6** menu. It and the quit key now
  close the game the way the window's close button does, finishing the
  photo, the last save backup and the Windows HDR switch first.
- **DualSense** settings are always listed; they stay greyed out until a
  DualSense is connected, and the status line says whether it is missing
  or held by Steam Input.
- **DLSS and FSR at native size** (#804): with a 1:1 resolution, temporal
  upscalers now run as anti-aliasing (DLSS as DLAA), and the resolution
  line says so.
- **Android**: on devices without a Qualcomm GPU, setup shows a hint at the
  top pointing to the opt-in that lets Mali, Tensor, Exynos and Dimensity
  GPUs start the game.

## Fixed

- **Updates that changed nothing** (#802): an update rebuilt nothing and
  kept launching the previous game, so new settings such as DLSS and FSR
  were missing. Updated sources now get the current time and rebuild.
- **White window after SET WRISTBAND**: the trainer wrote an invalid
  settings file, so every setting reset at each start. The value is
  quoted now, and a file an earlier build wrote is repaired at startup.
- **Play failed with an empty `pinyon_shift.toml`** (#793).
- **Android builds** on PCs without developer tools: no system git needed
  (#810), old Java 8 or JDKs without `keytool` are ignored and the pinned
  JDK is used (#811, #868), and long install folders unpack (#799).
  SDK package installs retry and name what failed.
- **Steam Deck and Linux**: setup builds in folders with spaces again, such
  as `Non-Steam Games/Forza Horizon` on an SD card (#727, #805).
- **macOS source builds** with current Xcode (#798).
- **Setup**: a failed FidelityFX header download no longer stops the build
  (#833); a compiler check that fails with cmd's "cannot find the path"
  names likely causes (#769); the disk-space error splits each drive's
  figure (#725).
- **Night glows**: street lamp and headlight glows no longer show through
  the player's car and the terrain (#803).
- **Intel GPUs on Linux (Mesa ANV)** no longer use Vulkan push
  descriptors; the #813 report measured two to three times the frame rate
  without them on an Arc B580.
- A crash in XMA audio decoding (#827).

## Faster

- **Save backups** no longer copy the whole save at every autosave. They
  run at the start of a session, at most every ten minutes after a save,
  and at exit, behind the game's own disk use. This removes the 100 % disk
  spikes and hitches at each save.
- **Depth buffers** at 4x samples share memory with their aliases: at 3x
  resolution on an RTX 4080 the GPU spends a median 1.09 ms less on each
  frame.

## Known limitations

- UDLC is checked with one car, the 2002 Acura RSX Type-S, bought and driven
  on the Windows base and v4 builds. Other cars, upgrades and their removal
  are not qualified, and some *Fast & Furious* cars stall in the paint
  shop. Keep a save backup.
- The hidden cars mod is not yet checked in game on v4.
- The v4 build on Linux and macOS is tested in scripted routes only.
- DualSense over Bluetooth or off Windows is untested.
- AMD and Intel GPUs on PCs are not qualified yet; the Steam Deck is.
- DLSS is Windows only.
