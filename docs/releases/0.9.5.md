# Pinyon Shift 0.9.5

An experimental Direct3D 11 renderer for Windows PCs whose GPU has no
Vulkan 1.3 driver.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.9.5**; the game is built again after the update, and saves,
settings and DLC stay where they are.

## New

- **Direct3D 11 fallback (experimental).** On Windows, when no GPU has a
  Vulkan 1.3 driver but one supports Direct3D feature level 11_0 (for
  example AMD Radeon HD 5000-6000, Intel HD Graphics 2500/4000 to Iris
  6200, or NVIDIA GeForce 400 to 700), the game starts on a new Direct3D 11 renderer instead
  of stopping with "Graphics unavailable". The launcher's hardware line
  shows "Direct3D 11 (experimental)". The settings keep Vulkan, so a driver
  update that adds Vulkan 1.3 switches back by itself. To try Direct3D 11
  on any Windows GPU, start the game with `--gpu_backend=d3d11`.

## Known limitations

- Direct3D 11 runs at 1x resolution only, and is slower than Vulkan on the
  same GPU (151 against 85 ms a frame on an Intel UHD 620 with the low-spec
  preset). It has been tested on an RTX 4080, an Intel UHD 620 and a
  GeForce 930MX, all of which also have Vulkan; it hasn't run on a GPU that
  has only Direct3D 11 yet. If it fails there, the message says so and
  `logs/runtime.log` in the game's data folder names the step.
- The limitations listed for [0.8.0](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.8.0.md#known-limitations) still apply.
