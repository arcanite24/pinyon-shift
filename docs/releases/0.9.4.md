# Pinyon Shift 0.9.4

A Windows setup fix for Visual Studio 18.12, and the Windows downloads that
0.9.3 was missing.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.9.4**; the game is built again after the update, and saves,
settings and DLC stay where they are. It also carries the 0.9.3 Android
launch fix ([0.9.3 notes](0.9.3.md)).

## Fixed

- **Windows setup stopped at its C++23 check** after Visual Studio was
  updated to 18.12. That version's MSVC 14.52 standard library accepts only
  Clang 22 or newer, and setup builds with the pinned Clang 20 (STL1000 in
  the log). Setup now picks the newest installed MSVC toolset that accepts
  the pinned Clang, and when Visual Studio 18 has none it installs the
  14.44 toolset beside the newer one.
- **0.9.3 had no Windows prebuilt kit, LLVM or host objects**, because the
  same problem stopped the release build that makes them, so first Windows
  setups on 0.9.3 built those from source. 0.9.4 ships all of them again.

## Known limitations

The limitations listed for [0.8.0](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.8.0.md#known-limitations) still apply.
