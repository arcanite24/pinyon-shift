# Pinyon Shift 0.9.1

A setup fix for updates to 0.9.0.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.9.1**; the game is built again after the update, and saves,
settings and DLC stay where they are.

## Fixed

- **Setup stopped on the first build after updating to 0.9.0** with "file
  ... has been modified since the precompiled header" (#1096, #1097,
  #1098). The ShiftGlue kit's files are unpacked with a fixed 1980 date, so
  the build reused precompiled headers made from the previous kit, or from
  an older MSVC after a Build Tools update. Setup now dates freshly unpacked
  kit files to the install time and remakes the precompiled headers when
  the kit, the compiler or the MSVC version changes. Players who deleted
  their build folder to get past it need do nothing more
  ([troubleshooting](https://arcanite24.github.io/pinyon-shift/troubleshooting/)).

## Known limitations

The limitations listed for [0.8.0](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.8.0.md#known-limitations) still apply.
